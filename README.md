# Course Reference Sheets

LaTeX reference sheets I wrote for my exams at the University of Oregon (B.S. Data Science, Mathematics and Business minors, 2026). Each one condenses a full course into two dense pages: definitions, formulas, decision rules for picking a method, and the traps I kept falling into.

| Course | Term | What it covers | Files |
|---|---|---|---|
| DSCI 372M Machine Learning for Data Science | Winter 2026 | Regression and gradient descent, regularization, calibration, imbalanced data, k-NN, neural nets and CNNs, trees and ensembles, SVMs, clustering, PCA, t-SNE, bandits, plus model and metric routing tables | [`DSCI372M_Machine_Learning/`](DSCI372M_Machine_Learning/) |
| MATH 467 Stochastic Processes | Spring 2026 | Markov chains (classification, stationary distributions, convergence, hitting times, absorbing chains, mixing rate), martingales, Brownian motion (Durrett Ch. 1 and 6) | [`MATH467_Stochastic_Processes/`](MATH467_Stochastic_Processes/) |
| MATH 281 Several-Variable Calculus I | Winter 2026 | Vectors, lines and planes, quadric surfaces, space curves, partial derivatives, gradients, tangent planes, optimization, Lagrange multipliers | [`MATH281_Multivariable_Calculus/`](MATH281_Multivariable_Calculus/) |
| MATH 461 Mathematical Methods of Statistics I | Fall 2025 | Counting, probability laws and Bayes, discrete and continuous distributions, Poisson processes, normal approximations, transformations | [`MATH461_Probability/`](MATH461_Probability/) |
| DSCI 345M Probability and Statistics for Data Science | Spring 2025 | Distribution reference table, CLT, inference, MLE and method of moments, OLS, robust models, GLMs (logistic, Poisson), regularization and cross-validation, PCA | [`DSCI345M_Probability_Statistics/`](DSCI345M_Probability_Statistics/) |
| DSCI 299 Data Structures in Python | Spring 2025 | Shell and command-line tools, Python scripting and file I/O, stacks, queues, linked lists, deques, heaps, hash maps, Big-O, sorting | [`DSCI299_Data_Structures/`](DSCI299_Data_Structures/) |
| BA 318 Finance: Creating Value through Capital | Spring 2025 | Time value of money, bond and equity valuation, NPV and IRR, risk and portfolios, CAPM, cost of capital and WACC | [`BA318_Finance/`](BA318_Finance/) |

Each folder has the LaTeX source and the compiled PDF. Build with XeLaTeX (`xelatex <file>.tex`); MATH 281 uses the `newtx` fonts.

These are public versions: worked homework, quiz, and practice-exam solutions have been removed so the sheets can be shared without giving away course problems. Concept sheets only.
